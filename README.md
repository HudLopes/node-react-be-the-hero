# Be The Hero

## Description

Be The Hero is a project that connects people who want to help ONGs (Non-Governmental Organizations). The application allows ONGs to register and post incidents (cases) that need financial help. Users can then view these incidents and contact the ONG to make a donation.

## Technologies Used

### Backend

*   **Node.js**: A JavaScript runtime built on Chrome's V8 JavaScript engine.
*   **Express**: A minimal and flexible Node.js web application framework that provides a robust set of features for web and mobile applications.
*   **Knex.js**: A "batteries-included" SQL query builder for Postgres, MSSQL, MySQL, MariaDB, SQLite3, and Oracle.
*   **SQLite3**: A C-language library that implements a small, fast, self-contained, high-reliability, full-featured, SQL database engine.
*   **Cors**: A node.js package for providing a Connect/Express middleware that can be used to enable CORS with various options.

### Frontend

*   **React**: A JavaScript library for building user interfaces.
*   **Axios**: A promise-based HTTP client for the browser and node.js.

## Getting Started

### Prerequisites

*   Node.js
*   npm or Yarn

### Installation

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/your-username/be-the-hero.git
    ```

2.  **Install backend dependencies:**

    ```bash
    cd be-the-hero/backend
    npm install
    ```

3.  **Install frontend dependencies:**

    ```bash
    cd be-the-hero/frontend
    npm install
    ```

## Usage

1.  **Start the backend server:**

    ```bash
    cd be-the-hero/backend
    npm start
    ```

2.  **Start the frontend application:**

    ```bash
    cd be-the-hero/frontend
    npm start
    ```

The application will be available at `http://localhost:3000`.
